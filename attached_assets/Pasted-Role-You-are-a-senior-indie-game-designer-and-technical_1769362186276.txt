Role:
You are a senior indie game designer and technical mentor specializing in game jams, minimalist mechanics, and psychological platformers like Level Devil and Geometry Dash.

Objective:
Help design and build a 2D single-screen platformer for a game jam, using p5.js, strictly following the theme “Equivalent Exchange.”
The game must be small, polished, and clever, not large or complex.

CORE CONSTRAINTS (DO NOT VIOLATE)

Platform: p5.js
Resolution: 800×600, scalable
FPS: 60
Total Levels: 8
No external assets (no sprites, no textures)

Visuals: Black background, white glowing geometry

Input:
Arrow keys or A/D/W → movement
Space → jump
Shift → switch form
Enter → start / confirm
Tab → pause menu (Resume / Restart / Exit)

Buttons:
Start Game
How to Play(Input Instructions)
Credits
Menu(to pause the game)

CORE GAME CONCEPT
Game Name - Balance is a Lie
Opening line (must appear before gameplay):
“Progress always removes something of equal value.”, then enter into the game.

Gameplay merges:
Geometry Dash (clean geometry, precision)
Level Devil (deceptive level design, expectation traps)

PLAYER FORMS (FIXED — DO NOT ADD MORE)
Form	Advantage	Cost (Equivalent Exchange)
Circle	Fast movement	Screen shrinks if idle for 3 seconds
Triangle	High jump	Gravity increases by 5% per jump
Square	Stability & control	Movement speed gradually decreases
Player can switch forms mid-level using Shift, and costs persist per level.

LEVEL DESIGN RULES
One screen per level
No randomness
Every death must be logically explainable
One new idea per level
Traps must look fair but behave unexpectedly
Levels must escalate psychological pressure, not mechanical difficulty

LEVEL STRUCTURE-
LEVEL 1 — “Trust”

Purpose: Teach controls + betray expectations lightly

Layout
Flat floor
Door clearly visible at right
No obstacles (or so it seems)

Twist
Nothing.
Door works normally.

Why it exists
Build trust.
Let the player relax.

LEVEL 2 — “The Floor”

Purpose: First betrayal

Layout
Same as Level 1
Floor looks identical

Twist
When player reaches 70% of the screen, floor disappears behind them
Player must keep moving forward

LEVEL 3 — “Idle Cost” (Circle Punishment)

Purpose: Introduce form-based punishment

Layout
Narrow horizontal corridor
Door at far right

Trigger
If Circle is active and player stops for 3 seconds:
Screen starts shrinking from the left
If Triangle or Square → no shrink

LEVEL 4 — “The Jump Lie” (Triangle Punishment)

Purpose: Weaponize jumping

Layout
Series of small platforms
Door on elevated ledge

Twist
Each jump:
Gravity increases
After ~4–5 jumps:
Player slams into ground
Misses platforms

Solution
Switch form mid-level
Or use fewer jumps

LEVEL 5 — “Stability Tax” (Square Punishment)

Purpose: Show slow death without killing instantly

Layout
Moving spike wall from left
Long corridor

Twist
Square’s speed reduction stacks
Wall eventually catches player

LEVEL 6 — “False Choice”

Purpose: Psychological Level Devil moment

Layout
Two doors:
Left: labeled “SAFE”
Right: unlabeled

Twist
“SAFE” door instantly kills
Unlabeled door advances

LEVEL 7 — “Greed”

Purpose: Punish overuse of advantage

Layout
Tall vertical shaft
Door at top

Twist
Using Triangle jump repeatedly:
Gravity ramps so high that
Final jump becomes impossible

Solution
Switch to Circle mid-air
Or plan jumps carefully

LEVEL 8 — “The Exchange” (Finale)

Purpose: Make the theme undeniable

Layout
Door visible but locked

Text on screen:
“What will you give?”

Mechanics
Player must:
Lose speed
Lose jump height
Lose screen space

Only after all three costs are triggered:
Door unlocks
Ending


ENDING REQUIREMENTS-
After Level 8:
Fade to black

Text appears: 
"You have finished the game"
"What did it cost?"
