Game Name - Balance is a Lie
A minimalist psychological platformer built for a game jam, inspired by Level Devil and Geometry Dash, designed to make the player experience the theme — not read it.

“Progress always removes something of equal value.”

Game Overview
Balance is a Lie is a 2D single-screen platformer where every advantage comes with a hidden cost. The game looks fair, clean, and simple — until it isn’t. There are no random deaths. Every failure is the result of a decision the player made.
The game is built around the game jam theme:
"Equivalent Exchange"
Instead of telling a story, the game enforces the theme mechanically.

Core Concept-
Three geometric forms
Each form grants power
Each power extracts a cost
Costs persist within a level
The player must willingly give things up to progress
Winning is not about skill alone — it’s about restraint.

Player Forms & Mechanics-
Form	Advantage	Cost (Equivalent Exchange)
Circle	Fast movement	Screen shrinks if idle for 3 seconds
Triangle	High jump	Gravity increases by 5% per jump
Square	Stable control	Movement speed gradually decreases
Forms can be switched mid-level
Costs stack and persist per level
No form is “correct” on its own

Level Design Philosophy-
Total Levels: 8
One screen per level
No randomness
One core idea per level
Traps are visually fair but behaviorally deceptive
Psychological pressure > mechanical difficulty
The difficulty comes from expectation vs reality, not reflexes.

Level List-
Trust
Builds confidence. Nothing goes wrong.

The Floor
The ground betrays you mid-progress.

Idle Cost
Standing still becomes dangerous — but only in one form.

The Jump Lie
Jumping too much destroys your ability to jump.

Stability Tax
Safety slowly kills you.

False Choice
The game lies directly to your face.

Greed
The faster you try to win, the harder the level fights back.

The Exchange
Looks harmless. Requires sacrifice to finish.
